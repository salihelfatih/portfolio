🧪 Portfolio Test Runner

Comprehensive testing suite for portfolio UX improvements

1. Home Page Preservation Tests Ready

Validates that the home page remains unchanged after UX improvements.

  • Hero section (subtitle, heading, photo, SVG animation)
  • Stats section (4 stats with correct values)
  • Framer Motion animations
  • Responsive layout at all breakpoints
  • Social links (GitHub, LinkedIn, Twitter)

2. Navigation & Routing Tests Ready

Validates navigation and routing functionality across all pages.

  • Navigation links to all pages
  • Internal vs external link handling
  • Theme persistence across navigation
  • 404 routing for invalid routes
  • Browser back/forward navigation

3. Responsive Behavior Tests Ready

Validates responsive layout at all breakpoints (mobile, tablet, desktop).

  • Mobile layout (<640px)
  • Tablet layout (640px-1199px)
  • Desktop layout (≥1200px)
  • Image scaling without distortion
  • Touch target accessibility

4. Accessibility Tests Manual

Manual accessibility testing guide with detailed instructions.

  • Touch target sizes (minimum 44x44px)
  • Keyboard navigation through accordions
  • Screen reader announcements
  • Focus indicators on interactive elements
  • axe-core accessibility audit

📋 How to Use This Test Runner

  1. Make sure your development server is running (npm run dev)
  2. Click a test button above to open the test in a new tab
  3. Open DevTools console (F12) in the new tab
  4. The test script will load automatically
  5. Run the test function shown in the console
  6. Review the results and fix any issues
